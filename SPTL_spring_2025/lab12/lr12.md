# ЛАБОРАТОРНАЯ РАБОТА №12
## Создание простого приложения для ОС Аврора.

---

## Цель работы
1. Освоить базовые принципы работы с графическими элементами в Qt Quick.
2. Научиться создавать и позиционировать элементы интерфейса в ОС Аврора.
3. Познакомиться с изменением стилей и добавлением текста в элементы.

---

## ФОРМИРОВАНИЕ ОТЧЕТА
В отчёте по лабораторной работе необходимо кратко изложить описание выполненных действий с использованием соответствующих команд, приложить скриншоты настроек и результатов тестов для наглядности. Также следует указать на возникшие в процессе работы проблемы и описать найденные способы их решения. В случае наличия контрольных вопросов, ответы на них должны быть интегрированы в текст.

---

## Ход работы

### Задание 1. Статический интерфейс
**Требуется:**
1. Три цветных квадрата (синий, красный, зеленый)
2. Горизонтальное расположение
3. Текст в синем квадрате
4. Кнопки управления

**Технические требования:**
- Компоненты Rectangle
- Row для расположения
- Text с anchors.centerIn
- Кнопки Button

### Задание 2. Интерактивные элементы
**Необходимо добавить:**
1. Переключатели цвета фона
2. Текстовое поле с кнопкой
3. Ползунок прозрачности

### Задание 3. Анимация
**Реализовать:**
1. Движение зеленого квадрата
2. Изменение цветов по кнопкам
3. Обновление текста

---

## Задание для самостоятельной работы 
1. Добавьте кнопки "Увеличить" и "Уменьшить", изменяющие размеры всех квадратов одновременно.
2. Реализуйте воспроизведение звука при нажатии кнопок.
