## Цель работы
1. Освоить базовые принципы работы с кнопками и обработки их состояний
2. Научиться создавать и использовать диалоговые окна

## ФОРМИРОВАНИЕ ОТЧЕТА
В отчёте по лабораторной работе необходимо кратко изложить описание выполненных действий с использованием соответствующих команд, приложить скриншоты настроек и результатов тестов для наглядности. Также следует указать на возникшие в процессе работы проблемы и описать найденные способы их решения. В случае наличия контрольных вопросов, ответы на них должны быть интегрированы в текст.

## Ход работы

### Задание 1: Управление кнопкой
**Требуется:**
1. Создать кнопку с текстом "Нажми меня"
2. Реализовать текстовое поле для отображения состояния
3. Настроить обновление текста при изменении состояния кнопки

**Технические требования:**
- Использовать компонент Button
- Применить Label для вывода состояния
- Реализовать обработчики событий pressed и released

### Задание 2: Диалог с вычислениями
**Требуется:**
1. Создать диалоговое окно с двумя полями ввода
2. Добавить кнопку подтверждения "Подтвердить"
3. Реализовать вычисление суммы введенных чисел

**Особенности реализации:**
- Использование TextField для ввода чисел
- Преобразование строк в числа с помощью parseInt()
- Вывод результата в консоль приложения
